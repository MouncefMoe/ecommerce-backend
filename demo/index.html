🔗 API Endpoints

Authentication

POST/api/v1/auth/register
POST/api/v1/auth/login
GET/api/v1/auth/me

Products

GET/api/v1/products
POST/api/v1/products
PATCH/api/v1/products/{id}

Shopping Cart

GET/api/v1/cart
POST/api/v1/cart/items
DELETE/api/v1/cart/items/{id}

Orders

GET/api/v1/orders
POST/api/v1/orders
POST/api/v1/orders/{id}/cancel

Payments

GET/api/v1/payments/methods
POST/api/v1/payments/process

Admin Dashboard

GET/api/v1/admin/dashboard
GET/api/v1/admin/analytics/sales

💡 Example Usage

Try this cURL command to test the API:

# Login to get access token curl -X POST "YOUR_API_URL/api/v1/auth/login" \ -H "Content-Type: application/x-www-form-urlencoded" \ -d "username=customer@demo.com&password=customer123" # List all products curl -X GET "YOUR_API_URL/api/v1/products" # Add item to cart (authenticated) curl -X POST "YOUR_API_URL/api/v1/cart/items" \ -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \ -H "Content-Type: application/json" \ -d '{"product_id": "...", "quantity": 1}'
